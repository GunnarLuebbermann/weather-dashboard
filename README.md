# Weather Dashboard

A web-based weather dashboard application that provides current weather information and forecasts.

## Features

- Current weather conditions
- Weather forecasts
- User-friendly interface
- Responsive design

## Installation

```bash
git clone https://github.com/username/weather-dashboard.git
cd weather-dashboard
npm install
```

## Usage

```bash
npm start
```

Open your browser and navigate to `http://localhost:3000`

## Technologies Used

- HTML/CSS/JavaScript
- Weather API integration
- Responsive web design
